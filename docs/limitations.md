# Limitations, Responsible Use, and Reproducibility

1. **Research scope:** This repository contains the behavioural analysis
   module, not the full TraceGuard AML platform.
2. **Data availability:** Source transaction data is not included.
3. **Checkpoint availability:** The final checkpoint is not distributed.
4. **Reproducibility:** Selected evidence is preserved, but complete
   end-to-end retraining is not possible from this repository alone.
5. **Evaluation:** Offline metrics do not establish real-world efficacy.
6. **Model output:** Raw logits must not be treated as probabilities.
7. **Fairness:** Evaluation across demographic, institutional, and
   geographic groups requires additional authorized data and analysis.
8. **Human oversight:** Outputs are decision-support signals only.
9. **Security/privacy:** Do not commit sensitive transaction records,
   credentials, private Drive paths, or personally identifying data.
10. **Lineage:** V1/V3 comparisons and final GELU L20 metrics are distinct
    experiments and must remain separately labeled.
