# Selected Evidence

This directory contains selected compact research artifacts.

- `evidence_manifest.json`: source-relative paths, repository filenames,
  sizes, and SHA-256 integrity hashes.
- Final-lock JSON/Markdown: canonical GELU L20 selection and evaluation.
- Sequence-length primary results and training histories: controlled
  experiment records.
- V1/V3 summary: a separate experiment lineage.

The original source dataset and model checkpoint are not included.
Do not interpret historical candidate evidence as the final model lock.
